# breakpoint-page

Landing page for Breakpoint, the local-first autonomous QA engineer. Plain HTML and CSS, no build step, served by GitHub Pages.

- `index.html`, `styles.css`, `assets/`: the site.
- Downloads come from this repo's GitHub Releases. The page links to
  `releases/latest/download/Breakpoint-arm64.dmg`, so publishing a new release with an asset of that name
  updates the download button without touching the site.
