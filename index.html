Built like a QA engineer, not a test script.

Repo first

Boots your stack in Docker with seeded data and test accounts. Mail and payments go to local mocks, never real providers.

Native browser use

With Claude, the model drives the browser through its own browser tools: real clicks, typing, tabs and screenshots.

Evidence for every bug

Continuous video, annotated before and after screenshots, network HAR, console and server logs, synced on one timeline.

Any model, your keys

Anthropic, OpenAI, Gemini, OpenRouter, Ollama, LM Studio or any OpenAI-compatible endpoint. Pick a model per role.

Local only

No cloud, no account, no telemetry. API keys are encrypted with your macOS keychain.

Handoffs, then fixes

Each bug becomes a Markdown handoff for your coding agent. Verified fix PRs are next on the roadmap.

Three steps to a test run.

  1. 01

    Add a key

    Bring a key for any provider and pick your models, or use a preset.

  2. 02

    Open a repo

    Breakpoint reads your compose file, Dockerfile or package.json and proposes how to boot it.

  3. 03

    Watch it test

    Follow the run live, steer it in plain English, and get findings with root cause and video.
