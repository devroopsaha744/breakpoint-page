    Claude Code plugin

    Claude does the thinking.
    Breakpoint gives it hands.

    Install the plugin and Claude Code gets 28 QA tools and a /qa skill. It plans the journeys, drives a real browser, decides what is a bug, fixes the code, and asks Breakpoint to replay the bug to prove the fix. Breakpoint never calls a model and needs no API key.

    • Every action reports back. Console errors, 4xx and 5xx responses and server exceptions come back with the click that caused them.
    • Bugs with receipts. Screenshots, a video clip, network and server logs, and the files in your repo most likely to blame.
    • Replay without a model. Recorded steps run again from a clean session and answer “still fires” or “fixed”.
    claude · tiny-shop

    How it works

    Find it, prove it, fix it, prove it again.

    1. 01

      Explore

      Journeys a real user takes, run in a sandboxed Chromium you can watch live. Every second is recorded.

    2. 02

      Catch

      Oracles flag console errors, failed requests, 404 pages, server exceptions and serious accessibility issues.

    3. 03

      Report

      A finding with repro steps, a clip, logs and suspect files, written as a handoff your coding agent can act on.

    4. 04

      Replay

      After the fix, the exact steps run again with no model in the loop. Green means fixed, not “looks fine to me”.

    Features

    Built like a QA engineer, not a test script.

    ◎

    Repo first

    Boots your stack in Docker from its compose file, Dockerfile or package.json, with seeded data, test accounts and database snapshots. Or attach to the dev server you already run.

    ⌁

    Native browser use

    With Claude, the model drives the browser through its own browser tools: real clicks, typing, tabs and screenshots, with OS-level input when a page fights back.

    ▶

    Evidence on one timeline

    Continuous video, before and after screenshots, HAR, console and server logs, synced so every bug has its moment on tape.

    ✉

    Safe by default

    Mail goes to a local catcher and payments to a Stripe mock, never real providers. The sandbox is only reachable from your machine.

    ⚿

    Any model, your keys

    The Mac app runs its own agent with Anthropic, OpenAI, Gemini, OpenRouter, Ollama or LM Studio. Keys stay in your macOS keychain.

    ⌂

    Local only

    No cloud, no account, no telemetry. Runs live in ~/.breakpoint, where the app and Claude Code both read them.

    Install

    Three ways in.

    The MCP server and the /qa skill in one install. Inside Claude Code:

    /plugin marketplace add devroopsaha744/breakpoint-page
/plugin install breakpoint@breakpoint

    Or from your terminal:

    claude plugin marketplace add devroopsaha744/breakpoint-page
claude plugin install breakpoint@breakpoint

    Then ask: “QA my app at http://localhost:3000 and fix what you find.” The first session builds the sandbox image, which takes a few minutes.

    Downloads the MCP server to ~/.breakpoint/mcp, installs the /qa skill and registers the server with claude mcp add.

    curl -fsSL https://devroopsaha744.github.io/breakpoint-page/install.sh | sh

    Prefer to read it first? View install.sh. Works with any MCP client: point it at node ~/.breakpoint/mcp/0.1.0/server.mjs.

    The desktop app runs the whole QA agent itself, with your own model keys, and shows runs from Claude Code too.

    Download Breakpoint for macOS · Apple Silicon

    Not notarized yet: open the .dmg, drag Breakpoint to Applications, then right-click it and choose Open. macOS asks once.

    You'll need

    • macOS 13+ on Apple Silicon (Mac app)
    • Docker: OrbStack, Docker Desktop, Colima or Rancher
    • Node.js 20+ (plugin and script)

    Logins

    Give Breakpoint test accounts in a breakpoint.json at your repo root, or pass them when the session starts. It never guesses real credentials.

    FAQ

    Questions.

    Does the Claude Code plugin call an AI model?

    No. Claude Code is the brain. The plugin is a browser, oracles, evidence and replay; it runs on your Claude Code plan and needs no API key.

    Does it work with apps made of several services or repos?

    Yes, through the UI: attach to the front end you already run, and every backend it calls is exercised and every failing request is caught. Suspect files and server logs come from the one repo you point it at today; workspaces that span several repos are on the roadmap.

    Will it touch my real data?

    When Breakpoint boots your repo, it uses throwaway containers with database snapshots and mocks for mail and payments. When it attaches to your dev server, it acts on your dev data, so point it at a dev environment, never production.

    Where do recordings go?

    Into ~/.breakpoint/runs on your machine. Nothing is uploaded.

    Why does macOS warn me when I open the app?

    This preview is signed locally but not yet notarized by Apple. Right-click the app and choose Open once; after that it opens normally.
